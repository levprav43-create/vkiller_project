# VKinder - Бот для знакомств ВКонтакте

## Описание
Бот для поиска интересных знакомств ВКонтакте

## Авторы
- Лев (VK API, бот)
- Владислав (База данных, документация)

## Установка и запуск
1. Установите библиотеки командой терминала pip install -r requirements.txt
2. Создайте и заполните .env файл
3. Создайте таблицы запустив python fix_db.py 
4. Запустите python main.py
5. Знакомьтесь и встречайтесь

## Команды бота
- /начать - начать поиск
- далее - следующий кандидат
- избранное - показать избранных
