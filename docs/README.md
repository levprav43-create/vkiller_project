# VKinder - Бот для знакомств ВКонтакте

Бот для поиска интересных знакомств ВКонтакте

## Авторы
- Лев (VK API, бот)
- Владислав (База данных, документация)

## Установка и запуск

### 1. Клонирование репозитория
git clone https://github.com/levprav43-create/vkiller_project.git
cd vkiller_project

### 2. Установка зависимостей
pip install -r requirements.txt

### 3. Настройка переменных окружения
1. Скопируйте .env.example в .env
2. Заполните .env своими значениями

### 4. Получение токена VK
1. Откройте https://vkhost.github.io/
2. Выберите Kate Mobile
3. Разрешите все права доступа
4. Скопируйте токен из адресной строки

### 5. Настройка группы VK
1. Создайте группу ВКонтакте
2. Включите сообщения сообщества
3. Узнайте ID группы: https://reg.ru/whois/admin.html

### 6. Создание таблиц БД
python fix_db.py

### 7. Запуск бота
python main.py

### 8. Начало работы
Напишите боту в сообщения группы: /начать

## Команды бота
| Команда | Описание |
|---------|----------|
| /начать | Начать поиск пары |
| далее | Показать следующего кандидата |
| нравится | Добавить в избранное |
| избранное | Показать список избранных |
| не нравится | Добавить в чёрный список |

## Схема базы данных
См. файл: схема_БД.jpg

## Таблицы
| Таблица | Описание |
|---------|----------|
| users | Пользователи бота |
| candidates | Просмотренные кандидаты |
| favorites | Избранные кандидаты |
| blacklists | Чёрный список |

## Технологии
- Python 3.x
- vk_api (Long Polling)
- SQLAlchemy + PostgreSQL
- python-dotenv
